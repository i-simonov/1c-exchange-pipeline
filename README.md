# 1c-exchange-pipeline

Ядро конвейера регистрации объектов к обмену для 1С:Предприятия.

Исходники расширения находятся в каталоге `src`. Ядро не содержит конкретных
планов обмена, прикладных объектов и реализаций обработчиков потребителя.

## Состав

- `КОД_ДиспетчерРегистрацииКОбмену` — запуск сценариев и управление контекстом регистрации.
- `КОД_КонвейерОбработчиковБазовый` — базовая реализация цепочки обработчиков.
- `КОД_ПодпискиНаСобытияПереопределяемый` — обработчики подписок перед записью и при записи.
- `КОД_ДиспетчерРегистрацииКОбменуПереопределяемый` — место связывания ядра с библиотеками потребителя.
- `КОД_РеестрСценариев_ИмяПланаОбмена` — встроенный шаблон реестра сценариев.
- `КОД_РучнаяРегистрация` — универсальный интерфейс ручного запуска сценариев.

Закомментированные примеры связок и интеграции с БСП сохранены непосредственно
в соответствующих объектах ядра.

Демонстрационная реализация находится в репозитории
[1c-exchange-pipeline-demo](https://github.com/i-simonov/1c-exchange-pipeline-demo).
